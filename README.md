# Horse Racing Simulator

A Python-based horse racing simulation program developed as a **first-year academic project** for the introductory Programming course at UPV. 

While simple in its scope, this early project demonstrates core foundational programming concepts, including logic structuring, modularity, and automated testing.

##  Features
*   **Simulation Logic:** Algorithmic race progression based on predefined parameters.
*   **Automated Testing:** Includes a comprehensive test suite (Unit Tests) to ensure logic reliability and edge-case handling.
*   **Documentation:** Comprehensive academic report covering the development process and architectural decisions.

##  Tech Stack
*   **Language:** Python 3.x
*   **Libraries:** (Check `requirements.txt` for full dependencies)

##  Repository Structure
*   `/assets`: Graphical assets (Icons, JPEGs) used in the project.
*   `/docs`: Contains the final academic report (PDF) detailing the project architecture.
*   `/tests`: Python test scripts for validating the simulation logic.
*   `Carrera_Caballos.py`: The main execution script.
